# 小树枝信使（FeoMessenger）

在手机上查看/发送《最终幻想 XIV》游戏内聊天消息的中继工具：电脑端（鲶鱼精邮差）把游戏聊天转发到手机，手机把消息命令发回电脑在游戏内发送。

- 版本：1.1.0
- 应用包名：`com.feomessenger`

## 功能

### 聊天中继
- 电脑端把游戏内聊天（小队 / 私聊 / 部队贝 / 系统 / 默语等）转发到手机端口，实时显示在聊天区
- 手机输入消息，自动加频道前缀（`/p` 小队、`/e` 默语、`/r` 回复、`/cwl1~8` 跨服贝、自定义前缀）后发回电脑在游戏内发送
- 命令行风格界面，等宽字体，可自定义各消息类型颜色与界面三区（顶部 / 聊天背景 / 底部）颜色

### 连接与验证
- 启动时自动验证连接电脑：延迟 1 秒发送 `/e 菲奥已上线`，电脑回传即静默置为在线，20 秒无回传判定离线
- 主界面顶部「测试」按钮：发送 `/e 菲奥在吗` 验证连接，收到回传后在屏幕显示系统消息「小树枝在线中」，不弹通知
- 停止服务时自动发送 `/e 菲奥已离线`，告知电脑端手机已离线
- 自动扫描子网（1~255）发现电脑 IP，也可手动填写验证
- 顶部实时显示手机 IP 与监听端口

### 通知管理
- 进入 App 自动清除本 App 的历史消息/状态通知
- App 在前台时：新消息只响通知音效，不弹通知打扰
- App 在后台时：新消息正常弹通知，点击通知直接打开主界面

### 其他
- 锁定竖屏运行，禁止转横屏
- 前台服务后台常驻收消息；可切换极简模式（无常驻通知，稳定性下降）
- 设置页支持：电脑 IP / 手机监听端口 / 电脑端口 / 自定义前缀与颜色 / 清空聊天记录 / 重启、停止服务

## 使用前提

1. 电脑端运行鲶鱼精邮差（默认监听端口 2019），并配置 GenericJson Action 把游戏消息转发到手机 `手机IP:2026`
2. 手机与电脑在同一 WiFi 下
3. 手机端在设置页填写电脑 IP（或使用自动扫描），电脑端口默认 2019

## 构建

```bash
./gradlew assembleRelease
```

产物位于 `app/build/outputs/apk/release/`。
